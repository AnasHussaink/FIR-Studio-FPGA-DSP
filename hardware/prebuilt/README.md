# Original hardware bitstream

`fir_uart_top.bit` is copied from the supplied project's completed implementation run. It targets **xc7a35ticsg324-1L**, with the Arty pin assignments in `constraints/arty_a7_35t.xdc`.

It was not rebuilt during repository packaging. Rebuild from the provided RTL for a new device or modified pinout. Configuration via JTAG is volatile; this repository does not configure boot flash.
